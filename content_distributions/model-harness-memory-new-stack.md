# Content Distribution: Model + harness + memory is the anatomy of a digital worker

## Twitter Thread

**Hook:** I almost called model + harness + memory the new software stack. Wrong frame. It's the anatomy of a digital worker.

**Pain points (the old SaaS shape that's breaking):**
- Per-seat pricing for something that replaces a $80K employee?
- IT-budget buyers for tools that should come out of payroll?
- "Software stack" framing for something that *uses* software?
- The TAM was always wrong

**The right frame:**
- Model = brain
- Harness = body (hands, eyes, procedures)
- Memory = experience

Once you see "agent = worker," the pricing follows ($0.99/resolved ticket, not $30/seat), the buyer follows (CFO, not IT), and the TAM follows (13% of GDP, not 1%).

**Sub-thesis:** mature workers write code. Code is more reliable than agents. The value of an agent is in how aggressively it compresses itself into deterministic scripts.

## LinkedIn Post

**Story:** I've been building memory systems for AI agents for months. I started writing a post calling model + harness + memory the new software stack — meant to replace frontend + backend + database. The framing broke as soon as I pushed on it.

**Problem:** Frontend + backend + database produces an application. Model + harness + memory produces something that *uses* applications, *writes* applications, talks to people, accumulates experience. That's not software. That's a worker.

**WTF moment:** Look at the 2026 pricing data. Intercom Fin charges $0.99 per resolved ticket. Sierra anchors against headcount budgets, not seat licenses. Sapphire's Cathy Gao: "Winning companies will look less like SaaS and more like managed labor." None of this is a software market — it's a labor market.

**Solution:** The right frame is agent = digital worker. Model is the brain. Harness is the body — hands, eyes, runtime. Memory is the experience. Once you see that, pricing, buyer, market size, and org chart implications all line up. The post also covers why mature agents write code (because code is more reliable than agents), and the read-pages/retain-memories architecture that I think is the right shape for agent memory.
